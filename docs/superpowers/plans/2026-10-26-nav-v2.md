# Navigation v2 (Phase 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lazy-load all routes, hide Your Fit, and add the 4-tab shopper bar behind a per-device flag (off by default).

**Architecture:** Pure, tested modules in `src/lib/` hold the rules (flag, tabs, redirects, Explore tabs, lazy retry); components only read them. `App.tsx` switches to lazy pages and picks the old or new bar from the flag.

**Tech Stack:** React 18, react-router 6, Vite, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-26-nav-v2-design.md`

## Global Constraints
- No change to Live Cam files (`src/components/ai-studio/live-cam/*`, `useLiveCamSession.ts`), `AiStudioModal.tsx` behaviour, or the Globe's behaviour (`Explore.tsx` keeps every tab except Fit).
- Flag `nav_v2` off by default; per-device opt-in via `?nav_v2=1`, stored under localStorage key `azyah:nav_v2`; `?nav_v2=0` clears it. Storage access wrapped in try/catch.
- `your_fit` flag false.
- Keep `npx vitest run src/components/ai-studio/live-cam` green. Don't commit `supabase/functions/mcp/index.ts`.

## Review Focus
1. A deep link that is a share/auth/AR URL with nav v2 on must not redirect. Test: `redirectFor('/share/outfit/x')` is null.
2. Query strings survive redirects. Test: `/discover?q=dress` → `/swipe?q=dress`.
3. Storage blocked (private mode) must not crash the flag. Test: storage that throws → returns the default.
4. A lazy chunk that fails twice must surface the error (no reload loop). Test in `lazyPage`.
5. `?tab=your-fit` on the Globe must open Brands, not a blank tab. Test in `exploreTabs`.

### Task 1: Rules modules (tests first)
**Files:** Create `src/lib/navV2.ts` + test, `src/lib/exploreTabs.ts` + test, `src/lib/lazyPage.ts` + test.
**Interfaces:**
- `resolveNavV2(search: string, storage: Pick<Storage,'getItem'|'setItem'|'removeItem'> | null, defaultOn: boolean): boolean`
- `SHOPPER_TABS: { id: 'discover'|'try-on'|'community'|'profile'; label: string; path: string }[]`
- `activeShopperTab(pathname: string): ShopperTabId | null` (discover: `/swipe`, `/explore`, `/discover`; try-on: `/try-on`; community: `/community*`; profile: `/profile` exactly, `/settings`, `/favorites`, `/rewards`, `/dashboard*`)
- `navV2RedirectFor(pathname: string, search: string): string | null` (`/discover`→`/swipe`; `/feed`,`/forum`,`/fashion-feed`,`/dress-me/community`→`/community`; query kept)
- `showShopperBar(pathname: string): boolean` (false on `/onboarding*`, `/auth*`, `/reset-password*`, `/brand-portal*`, `/retailer-portal*`, `/ar/*`, `/dress-me*`, `/share/*`, `/terms`, `/privacy`, `/cookies`, `/`, `/landing`, `/kiosk*`)
- `visibleExploreTabs(yourFit: boolean): ExploreTab[]`; `resolveExploreTab(param: string | null, yourFit: boolean): ExploreTab`
- `lazyPage<T>(factory: () => Promise<{default:T}>, deps?: { storage, reload })`: retries by reloading once per session (key `azyah:chunk-reload`), then rethrows.

### Task 2: Lazy routes
**Files:** Modify `src/App.tsx`. Every page import becomes `lazyPage(() => import(...))`; `<Routes>` wrapped in `<Suspense>` with a small spinner. Providers, guards, nav, `ErrorBoundary` stay eager. Verify: build passes and the main chunk shrinks.
